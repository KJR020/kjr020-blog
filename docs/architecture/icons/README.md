# Architecture diagram icons

`blog-architecture.drawio`とREADME用SVGで使用するロゴの原本。Reactロゴは図の検討時に取得した候補で、現行図には配置していません。

| ファイル | 出典 | 備考 |
| --- | --- | --- |
| `github.svg` | [GitHub Brand Toolkit](https://brand.github.com/foundations/logo) | 公式Invertocat。形状・縦横比・色を変更せず使用する |
| `cloudflare.svg` | [Simple Icons](https://simpleicons.org/?q=cloudflare) / [Cloudflare Press Kit](https://www.cloudflare.com/press/press-kit/) | 公式プレスキットはラスター配布のため、ベクター形状はSimple Iconsを使用 |
| `markdown.svg` | [Simple Icons](https://simpleicons.org/?q=markdown) | Repository内の技術識別用 |
| `astro.svg` | [Simple Icons](https://simpleicons.org/?q=astro) / [Astro Press Resources](https://astro.build/press/) | Astro Buildの識別用 |
| `react.svg` | [Simple Icons](https://simpleicons.org/?q=react) | 未使用。クライアント側コンポーネントの候補ロゴ |
| `github-actions.svg` | [Simple Icons](https://simpleicons.org/?q=githubactions) | Deploy workflowの識別用 |

取得日: 2026-09-17

各ロゴ・名称の商標権はそれぞれの権利者に帰属する。図中では技術・サービスの識別だけに使用し、提携や推奨を示すものではない。
