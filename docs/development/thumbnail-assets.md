# サムネイル素材の出典

`src/assets/thumbnails/logos/` の Astro、React、TypeScript、Python の SVG は [Simple Icons](https://github.com/simple-icons/simple-icons) 16.30.0 から取得した。Simple Icons は CC0 1.0 で配布されているため、生成時に外部URLへ接続せず、リポジトリ内のファイルを入力として使う。

ロゴの更新時は、Simple Icons のバージョン、対象アイコン、ライセンスを確認してからファイルと依存バージョンを同じ変更で更新する。商標の利用条件は各プロジェクトのガイドラインにも従う。
